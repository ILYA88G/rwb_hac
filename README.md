# Capibara — аналитическая модель маркетплейса

## О проекте

Проект команды в рамках хакатона Capibara. Цель — построить аналитическую модель данных маркетплейса на PostgreSQL, преобразовать исходные данные и подготовить SQL-запросы для анализа продаж.

В основе — датасет Brazilian E-Commerce Public Dataset by Olist: 550 759 строк в восьми исходных таблицах за период с сентября 2016 по октябрь 2018 года.

## Задачи проекта

- Спроектировать модель данных в схеме `core`.
- Преобразовать и очистить данные из `raw`, не изменяя исходный слой.
- Реализовать таблицы заказов, позиций заказов, платежей, отзывов и справочников.
- Подготовить SQL-запросы для аналитических вопросов.
- Проверить корректность ключей, зерно таблиц, потери при соединениях и согласованность сумм.
- Разработать концепцию аналитического дашборда и стратегию развития модели.

## Быстрый старт

### Требования

- Docker Desktop с поддержкой Docker Compose.
- Git.
- SQL-клиент: DBeaver или `psql`.
- Для загрузки исходных данных — Python 3.10+.

### Запуск окружения

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <ИМЯ_РЕПОЗИТОРИЯ>
```

Запустите подготовку базы данных:

```bash
bash scripts/setup.sh
```

Параметры подключения к PostgreSQL:

- Хост: `localhost`
- Порт: `5432`
- База данных: `marketplace`
- Пользователь: `hack`
- Пароль: `hack`

**Важно:** команда запуска через `bash` подходит для Git Bash или WSL в Windows, а также для Linux и macOS. Команду сброса базы `bash scripts/setup.sh --reset` используйте только при необходимости полностью пересоздать окружение: она удаляет существующую базу с данными.

## Архитектура данных

| Схема | Назначение |
|---|---|
| `raw` | Исходные данные без изменения содержимого |
| `core` | Аналитическая модель данных |
| `mart` | Дополнительные витрины и сохранённые результаты, если потребуются |

Исходный слой `raw` не изменяется. Преобразование типов, очистка данных и правила построения аналитических сущностей реализуются при загрузке в `core`.

## Структура репозитория

```text

├── docs/
│   ├── handout.md
```

В папке `model/` размещаются материалы команды. По мере реализации модели здесь также будут находиться SQL-скрипты загрузки, построения таблиц и проверок качества данных.

## Командная работа

- Изменения фиксируются в Git с понятными сообщениями коммитов.
- Перед началом работы участники синхронизируют локальную ветку с удалённой.
- Изменения чужих файлов согласуются с их ответственными авторами.
- Аналитические ответы рассчитываются по таблицам `core`, а не напрямую по `raw`.
- Решения и использование ИИ документируются в соответствующих файлах.

## Статус проекта

Проект находится в разработке. Структура аналитической модели, SQL-скрипты, проверки качества, ответы на аналитические вопросы и концепция дашборда будут дополняться по мере работы команды.
