# Решения модели

Рабочий конспект. В «Принято» вносить только решения, явно подтверждённые командой. Слой `raw` не менять.

- Проверки покупателей, продавцов, товаров и категорий: [заполнить].
- Ключ человека и ключи остальных справочников: [заполнить после проверки].

## Факты (архитектура)

| Сущность | Предполагаемое зерно | Кандидат ключа / источник | Статус |
|---|---|---|---|
| Заказ | Один заказ | `order_id`, `raw.orders` | Подтвердить |
| Позиция заказа | Одна позиция | `(order_id, order_item_id)`, `raw.order_items` | Проверить уникальность |
| Платёж | Один платёж заказа | `(order_id, payment_sequential)`, `raw.order_payments` | Проверить уникальность |
| Отзыв | Уточнить | `raw.order_reviews` | Проверить ключ и зерно |
| Покупатель | Один бизнес-идентифицированный человек | `raw.customers` | Подтвердить ключ |
| Продавец | Один продавец | `seller_id`, `raw.sellers` | Подтвердить |
| Товар | Один товар | `product_id`, `raw.products` | Подтвердить |
| Категория | Категория товара | `raw.products` + `raw.product_category_translation` | Уточнить ключ и перевод |

## Проверки (качество)
- [ ] Число строк и уникальность ключей.
- [ ] Заказы без позиций и платежей.
- [ ] Сравнение платежей с `price + freight_value`.
- [ ] Потери строк при соединениях.
- [ ] Полнота категорий и сверка категорий с общим итогом.
- [ ] Источники, зерно и знаменатели этапов воронки.
- [ ] Поля выручки, комиссии, статусы и возвраты.

## Метрики, предложенные командой
1. Конверсия показов в клики: `Clicks / Seen`.
2. Конверсия кликов в добавления в корзину: `Send-to-cart / Clicks`.
3. Конверсия добавлений в запросы на покупку: `Buy-request / Send-to-cart`.
4. Конверсия запросов в реальные покупки: `Bought / Buy-request`.
5. Реальная выручка за период после комиссии.
6. Средняя стоимость купленного товара за период.
7. Потенциальный относительный рост прибыли при покупке всех запрошенных товаров.

Это предложения, не подтверждённые результаты. Формулы и источники утверждают владельцы метрик и архитектуры. Для прибыли необходимы данные о марже/себестоимости.
